# GitHub Portfolio Critic Agent

AI-агент (LangGraph, ReAct-патерн), що аналізує публічний GitHub-репозиторій
і дає структурований технічний фідбек — так, як це робить справжній технічний
рев'ювер перед прийняттям рішення про наймання.

## Чому це "справжній" AI-агент, а не просто виклик LLM

Замість одного фіксованого промта, агент **сам вирішує**, у якому порядку
викликати інструменти:
1. Спочатку дивиться загальну інформацію про репозиторій
2. Потім переглядає структуру файлів
3. **Сам вирішує**, у які конкретні файли варто заглянути (README, тести,
   основний код) — це рішення приймає LLM у процесі роздумів, а не
   заздалегідь прописаний сценарій

Це і є суть **tool-calling агента**: LLM отримує набір інструментів з
описами, і сам, крок за кроком, вирішує, як їх використати для
досягнення мети.

## Інструменти (tools) агента

- `get_repo_info` — загальна інформація (опис, мова, розмір)
- `list_repo_files` — структура файлів у репозиторії
- `get_file_content` — вміст конкретного файлу

## Встановлення

```bash
pip install -r requirements.txt
```

Отримай безкоштовний ключ Groq на [console.groq.com](https://console.groq.com)
(без картки), створи `.env` на основі `.env.example`.

## Швидка перевірка (без LLM)

Перед запуском повного агента, перевір, що самі інструменти працюють:

```bash
python test_tools_manually.py
```

Це протестує GitHub API tools на маленькому публічному репозиторії
(`octocat/Hello-World`), без виклику LLM — щоб одразу зрозуміти,
де саме проблема, якщо щось не спрацює.

## Запуск

```bash
python main.py
```

Введи посилання на будь-який публічний GitHub-репозиторій, наприклад:
```
MAJIbTA26/password-strength-checker-flask
```

## Обмеження

- Працює тільки з **публічними** репозиторіями (без токена)
- GitHub API має ліміт 60 запитів/год без авторизації — для аналізу
  одного репозиторію цього достатньо, але для масового використання
  знадобиться Personal Access Token
- Вміст файлів обрізається до 3000 символів, щоб не витрачати забагато
  токенів на один файл
